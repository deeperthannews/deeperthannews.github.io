Deeper Than News

Privacy Policy

Effective October 7, 2026

This policy covers Deeper Than News Uploader, the internal publishing tool of the Deeper Than News YouTube channel. The tool is operated by the channel itself and is used only to upload and manage videos on the channel's own YouTube account. It is not offered to the public and does not sign in, or collect information from, anyone else.

YouTube API Services

The tool uses YouTube API Services to upload videos, set titles, descriptions, thumbnails and captions, and change a video's visibility on the Deeper Than News channel. By using this tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool accesses

  • An OAuth access token and refresh token for the channel's own Google account, with the scopes youtube.upload and youtube.force-ssl.
  • Basic information about the videos it uploads (video ID, title, privacy status) returned by the API.

How it is used and stored

  • Tokens are stored only on the channel operator's own computer or server, in a file readable only by its owner. They are used solely to make API requests on behalf of the channel.
  • No data is sold, shared with third parties, used for advertising, or combined with other data.
  • The tool does not access viewers' data, comments, subscribers' personal information, or any other user's account.
  • Upload records (video ID and title) are kept locally for as long as the channel needs them for its own bookkeeping, and the tool keeps no other API data. Stored API data is refreshed or deleted within 30 days.

Cookies

The tool is a command-line program and does not use cookies. This website does not use cookies or analytics.

Revoking access

Access can be revoked at any time from the Google account's security settings at security.google.com/settings/security/permissions. Revoking access stops the tool from making any further requests; locally stored tokens are then deleted.
